# Sistema de Reserva de Espaços | UnB - FGA

Projeto desenvolvido para a disciplina de Orientação a Objetos (OO), com foco em boas práticas de programação orientada a objetos e estrutura modular em Java.

## Funcionalidades

- Cadastro de usuários (alunos, professores, técnicos)
- Consulta e reserva de espaços físicos
- Prevenção de conflitos de horário
- Cancelamento e histórico de reservas

## Tecnologias

- Java 21
- Lombok
- Arquitetura em camadas (MVC)

## Conceitos Aplicados

- Encapsulamento
- Herança e polimorfismo
- Generics
- Tratamento de exceções customizadas
